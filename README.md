# フラッシュテキスト

フラッシュテキストは、長文のテキストを短い長さで高速に表示することで、速読を支援するWebアプリケーションです。

## 特徴

- テキストを指定した文字数でフラッシュ表示
- 表示速度の調整（プリセット: 低速、中速、高速、カスタム）
- 表示文字数の調整（1〜10文字）
- シンプルで使いやすいインターフェース
- レスポンシブデザイン
- ダークモード対応
- 進捗表示機能

## 技術スタック

- Next.js 15
- TypeScript
- Tailwind CSS
- React 19
- Radix UI
- shadcn/ui
- React Hooks
- Lucide Icons

## 使い方

1. テキストエリアに読みたい文章を入力します
2. 表示速度をプリセットから選択します（低速、中速、高速、カスタム）
3. 表示文字数をスライダーで調整します（デフォルト: 5文字）
4. 「開始」ボタンをクリックすると、テキストが指定された速度と文字数で表示されます
5. 「停止」ボタンをクリックすると、表示が停止します
6. 「リセット」ボタンで最初からやり直すことができます

## 開発環境のセットアップ

```bash
# リポジトリのクローン
git clone https://github.com/hiroyannnn/flash-text.git
cd flash-text

# 依存関係のインストール
pnpm install

# 開発サーバーの起動
pnpm dev
```

アプリケーションは <http://localhost:3000> でアクセスできます。

# EPUB取り込み（試験版）

`kindle-capture` の `collect` → `recognize` → `export` で作成した `.flashbook.zip` も選択できます。元画面画像とOCR本文を端末内に保存し、確認対象の図表や読み順不明箇所では再生を止めます。「元画像」で確認してから「確認して続ける」を押してください。取得は最大20画面の検証用で、表示される進捗は取り込み済み範囲だけです。

ブラウザで公式にダウンロードできる暗号化されていないEPUBを選ぶと、本文を端末内のIndexedDBに保存します。本の一覧から「続きから」を押すと、前回表示した位置から再開できます。本文の取り込みや保存のためにサーバーへアップロードする処理はありません。

本文はEPUBのspine順にプレーンテキストとして抽出します。見出しと段落の区別と元のXHTMLファイル名を保存しますが、図表、ルビ、脚注、画像、縦書きの配置はこの版では再現しません。取り込み済み範囲の進行表示であり、原著の読了判定ではありません。

暗号化されたEPUBは取り込めません。ブラウザのサイトデータを消すと本と読書位置も消えるため、元のEPUBファイルは保管してください。上限はEPUB本体20MB、抽出本文500万文字です。

## 貼り付けテキストと .txt の保存

貼り付けて「開始」を押すと、本文をこのブラウザの IndexedDB に独立した文書として保存します。先頭の空でない行をタイトルに使い、保存後は「タイトルを保存」で変更できます。UTF-8 の `.txt` も同じ本棚へ取り込めます。上限は本文・ファイルともに 1MiB、タイトルは60文字です。

「新しいテキスト」で入力した文章は別文書になります。同じ本文でも既存の文書や読書位置を上書きしません。本棚の「続きから」で、文書ごとの位置と読了状態を停止したまま復元します。速度と表示文字数も同じブラウザ内で保持します。

本文の保存に失敗しても、その画面では読めます。警告が出た場合はページを閉じる前に「本文の保存を再試行」を押してください。破損した保存文書は本棚から隔離して件数を表示し、元データは削除しません。保存・取り込みのために本文を外部へ送る処理はありません。別のブラウザや端末とは同期せず、サイトデータを消すと本文と進捗も失われます。
